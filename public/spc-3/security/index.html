Security

Evidence before financial activation.

PRE-LAUNCH Financial services are not enabled.

Verified engineering checks

Local integration tests cover monetary conservation, replay protection, atomic journals, recovery behavior and gas separation. Provider checks verified a shared finalized Base Sepolia block and advertised EntryPoint support on November 14, 2026.

Limits of that evidence

Test success does not prove live custody, legal qualification, market safety, deployed code identity or resilience to every attack. External review is advisory; actual security and operational acceptance remain required.

Report concerns

Use the contact page to report a security concern. Do not include private keys, passwords or customer data. No bug bounty or response-time commitment is currently advertised.

Responsible disclosure

Contact the project with a concise description and safe reproduction steps. Do not send credentials, recovery secrets, customer records or exploit funds. No response-time or bounty promise is made. The machine-readable security contact identifies the same channel.
